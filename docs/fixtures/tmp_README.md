# 합성 테스트 자료

이 폴더는 실제 제품/영양소/공식 문서를 모방해 근거를 만들어내기 위한 자료가 아닙니다. 경계값과 실패 경로를 일정하게 재현하기 위한 합성 자료입니다. 테스트 폴더의 fixture로 읽고 실제 CSV 적재나 상담용 문서 저장소에는 합치지 않습니다.

- `intake_test_cases.json`: 가상의 TEST_NUTRIENT_A를 이용한 합산 계산. 숫자 100은 임의로 정한 테스트 경계이며 실제 섭취기준이 아닙니다. 1 mg = 1,000 ug인 단위 변환 외에 생물학적 변환을 정의하지 않습니다.
- `rag_test_corpus.json`: 가상 서비스 문서를 이용한 검색과 인용 테스트. `example.invalid`는 실제 출처가 아닙니다. source_type=synthetic이므로 실제 상담 코퍼스 검증에서는 거부해야 합니다.

기대 결과는 수업용 구현 계약입니다. 원본 데이터의 의학적 타당성을 검증하지 않습니다.
